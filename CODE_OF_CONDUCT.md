# Code of conduct

This project welcomes contributors of all backgrounds and experience levels.

## Expected behavior

Be respectful and specific. Critique ideas and behavior rather than people. Assume good faith, accept corrections, and make room for different perspectives. Keep feedback relevant to the project.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized content, personal attacks, doxxing, and publishing private information without permission are not acceptable. Neither is repeated disruption after a maintainer asks it to stop.

## Scope and enforcement

These expectations apply to issues, pull requests, discussions, and other project spaces. Maintainers may edit or remove content, close conversations, or restrict participation when necessary, including their own conduct being subject to the same expectations.

Report abusive content using GitHub's reporting tools and notify the maintainer by mentioning `@enzodevs` only when safe. Do not post private details or sensitive accusations in a public issue. For private abuse reports, use [GitHub's abuse reporting process](https://docs.github.com/en/site-policy/acceptable-use-policies/github-community-guidelines#reporting-abuse). Use the separate [security policy](SECURITY.md) for software vulnerabilities.
